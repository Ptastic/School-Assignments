# Video Game Sales Dashboard

An interactive Streamlit dashboard exploring video game sales, scores and console performance across manufacturers.

## Features

- Interactive sales trends by manufacturer and console over time
- Scatter plots of Metascore vs Global Sales
- Console sales overview by company
- Multi-page navigation

## Tech Stack

- **Streamlit** – Web app framework
- **Pandas** – Data handling
- **Plotly** – Interactive visualizations
