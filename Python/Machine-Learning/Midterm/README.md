# Midterm Assignment – Student Performance Prediction

Predict final exam scores and pass/fail outcomes based on student study habits and other features.

## Overview

This project uses a student dataset to build both **regression** and **classification** models.

### Goals
- Predict `Final_Score` (Regression)
- Predict `Pass` / Fail (Classification)

## Features Used
- Study Hours
- Attendance
- Previous Score
- Extracurricular activities
- Sleep Hours
- Semester

## Models Implemented
- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest

## Files
- `nb_ptastic.ipynb` – Complete Jupyter notebook with all models, evaluations and visualizations
- `student_data.csv` – Dataset used in the assignment

## Key Techniques
- Train/test split (80/20)
- Model evaluation (R², MSE, Accuracy, Confusion Matrix)
- Feature importance analysis
- Visualization of decision trees and results
