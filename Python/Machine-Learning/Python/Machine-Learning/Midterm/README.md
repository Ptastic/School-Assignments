# Machine Learning Assignments

School projects covering supervised and unsupervised learning using Python (scikit-learn, pandas, matplotlib).

## Projects

### 1. Midterm Assignment – Student Performance Prediction
Predict final exam scores (regression) and pass/fail (classification) based on study habits and other features.

**Models used:**
- Linear Regression
- Logistic Regression
- Decision Tree
- Random Forest

**Files:**
- `Midterm/nb_ptastic.ipynb` – Full Jupyter notebook
- `Midterm/student_data.csv` – Dataset

### 2. Final Assignment
Covers multiple machine learning techniques:

- Linear & Logistic Regression
- Decision Trees & Random Forest
- K-Means Clustering
- PCA + Silhouette analysis
- Model comparison (supervised vs unsupervised)

**Files:**
- `Final-Assignment/Final_assigment_Paul.docx` – Complete report with analysis and visualizations
